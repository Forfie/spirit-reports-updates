# Spirit Reports downloads

Fundraising reports for Spirit Radio's admin staff on macOS. Spirit Reports keeps a copy of the station's Bloomerang giving history on your Mac and turns it into the monthly income actuals, retention and attrition, donor lifespan, giving levels and donor locations, ready to export to Excel.

**[Download the latest version →](https://github.com/Forfie/spirit-reports-updates/releases/latest)**

1. Open the `.dmg` and drag **Spirit Reports** into **Applications**.
2. Open it. On a Mac that has used Spirit Reports before, your reports are there straight away, and it catches up with Bloomerang in a few seconds.
3. First time on this Mac? Ask the admin office for the staff installer instead. It includes the Bloomerang connection and the donor history, which are never posted here.

Spirit Reports is signed and notarized by Apple, so it opens without security warnings, and it keeps itself up to date. Requires macOS 14 or later.

This repository only hosts release downloads. It never contains the Bloomerang key or donor data.
